# ra9fael.port — Win顺 端口占用查询插件

`port 8080` 一步查出占用端口的进程并支持结束；纯 iphlpapi 结构化数据，不解析 netsh。与 winshun.kill（按名字/PID 杀）互补，补上「端口」维度。
